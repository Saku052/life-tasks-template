# デイリー（会社 + 私用）

## 手順

### 1. 現状を取る

```bash
./office.py board --json
./office.py stale 7
```

`personalError` が入っていたら、私用タスクは取れていない。その旨を一言添えて会社のタスクだけで進める。

### 2. 今日やることを絞る

会社と私用をまとめて、以下の順で拾い **最大5件** に絞る。

1. 期限が今日〜3日以内のもの
2. `P0` のもの
3. すでに `In progress` のもの
4. Pending のうち、待ち対象が解消していそうなもの

仕事中に手を付けられない私用タスク（通院・手続きなど）は、「今日の私用」として別に1〜2件だけ挙げる。
空き時間の推定はしない。どれだけ着手するかはユーザーが決める。

### 3. 報告

この順で、簡潔に。

1. **今日やる（最大5件）** — 番号・タイトル・理由（期限 / 優先度）
2. **今日の私用** — あれば
3. **詰まっているもの** — Pending と待ち対象、WIP上限超過（会社 + 私用の合計）
4. **放置気味** — `stale` に出たもの（あれば）

着手が決まった会社のタスクは `./office.py start <番号>` を実行する。
私用のタスクはこのPCからは動かせないので、提案だけにとどめる。
