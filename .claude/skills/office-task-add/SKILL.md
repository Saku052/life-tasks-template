# 会社タスクの起票

ユーザーの言葉を、あとから見て手が動くタスクに変換して `./office.py add` で登録する。

## 手順

### 0. 準備

- `profile.md` があれば読む。案件名 → ラベルの対応や、定例・締切の傾向が書いてある
- 私用の用事（通院・手続き・プライベートの予定など）だと分かる場合は登録しない。
  「私用のタスクは私用のスマホかPCから追加してください（このPCからは閲覧のみです）」と返す

### 1. 曖昧さを潰す

| 項目 | 埋め方 |
|---|---|
| title | 動詞で終える。20〜30文字。固有名詞を入れる |
| summary | 1〜3行。**なぜ今やるのか / 期限の根拠**を必ず入れる |
| check | 実行可能な単位に割る。3〜7個。1項目=1アクション。「調べる」で止めない |
| dod | 完了条件。Done と言い切れる状態 |
| due | 「〜までに」は前日、「今週中」は金曜、「今月中」は月末。推定したら summary に根拠 |
| priority | 締切3日以内 / 落とすと信用を失う → P0、今月内 / 誰かを待たせている → P1、それ以外 → P2 |
| label | `profile.md` の対応表。無ければ案件名や「定例」「レビュー」「事務」など。2つまで |

判断材料がそろっていれば聞き返さない。期限や対象が本当に分からないときだけ1回で聞く。

### 2. 登録

```bash
./office.py add \
  --title "週次定例の資料を作る" \
  --summary "金曜の定例で進捗を報告する。『今週中』と言われたため金曜を期限に設定" \
  --check "先週の数字を集める" --check "スライドにまとめる" --check "上長に事前共有する" \
  --dod "定例で資料を使って報告できた" \
  --label 定例 --priority P1 --due 2026-09-25
```

すでにやり始めているなら `--status "In progress"` を付ける。

### 3. 報告

番号（`W3` など）・タイトル・優先度・期限を1〜2行で返す。
複数まとめて頼まれたら、全部登録してから一覧で返す。

## 注意

- `profile.md` の対応表に無い語で判断が固まったら、対応表への追記を提案する（勝手に書き換えない）
- 5分で終わる用事は登録しない。その場でやるよう伝える
