# ボードの確認と更新

## ボードを開く

「ボード開いて」「見せて」と言われたら:

```bash
./office.py open
```

ブラウザでカンバンが開く。会社のカードはドラッグで移動・チェックでき、私用のカードは閲覧のみ。

## 状況を読む

```bash
./office.py board          # 会社 + 私用
./office.py board --json   # 細かく判断したいとき
```

報告は要点だけ。In progress の件数、期限が近いもの、Pending の待ち対象。生出力は貼らない。
WIP上限（In progress 5 / Pending 10）は会社と私用の合計で見て、超えていたら指摘する。

## 会社のタスクを動かす

番号は `W3` でも `3` でもよい。

| 言われたこと | コマンド |
|---|---|
| 「W3 やる」「着手」 | `./office.py start 3` |
| 「W3 止まってる、〇〇待ち」 | `./office.py move 3 pending --reason "〇〇待ち"` |
| 「W3 やっぱり後で」 | `./office.py move 3 todo` |
| 「W3 の〇〇終わった」 | `./office.py check 3 "〇〇"` |
| 「W3 終わった」 | `./office.py done 3` |
| 「W3 の期限を10/1に」 | `./office.py due 3 2026-10-01` |
| 作業メモ | `./office.py note 3 "..."` |

- ステータスはユーザーが言ったときだけ動かす
- Pending には必ず待ち対象を付ける。分からなければ聞く
- `done` が未消化チェックで止まったら、残項目を見せて「完了にしてよいか」を聞く。了承されたら `--force`

## 私用のタスク（`#12` など）

このPCからは**閲覧のみ**。変更を頼まれたら
「私用のタスクは私用のスマホかPCから操作してください」と返す。

## 棚卸し

「棚卸しして」と言われたら:

```bash
./office.py board
./office.py stale 7
```

In progress の詰まり、7日動いていない会社のタスク、待ちが解けていそうな Pending を挙げ、
To do に戻す / 完了にする / 捨てる、をユーザーに提案する（勝手には動かさない）。
