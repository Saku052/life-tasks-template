# タスク起票

ユーザーの言葉を、あとから見て手が動く Issue に変換する。

## 前提

`scripts/project.env` が存在すること。無ければ `./scripts/bootstrap.sh` を先に実行する。

## 実行手順

### 0. プロフィールを読む（毎回・最初に）

`docs/profile.md` を読む。ここにタイトル・ラベル・優先度・期限を決めるための材料が入っている。

特に次の4つは**そのまま適用する**。自分の判断で上書きしない。

- **固有名詞 → ラベル 対応表** — 発言に含まれた語からラベルを機械的に決める
- **タイトルの付け方** — 命名規則
- **優先度の既定** — 明示がないときの P0/P1/P2 判定
- **期限の推定** — 「今週中」などからの `Due` 算出

対応表に無い語が出てきて、かつ判断が固まったら、
`docs/profile.md` の対応表に1行追記することを提案する（勝手に書き換えない）。

プロフィールがまだ空欄だらけの場合は、その項目だけユーザーに聞く。

### 1. 曖昧さを潰す

ユーザーの発話は「賃貸の更新やらないと」程度の粒度で来る。以下が埋まらないと Issue にしない：

| 項目 | 埋め方 |
|---|---|
| title | `profile.md` の「タイトルの付け方」に従う |
| summary | 1〜3行。**なぜ今やるのか / 期限の根拠**を必ず入れる |
| check | 実行可能な単位に割る。3〜7個が目安。1項目=1アクション |
| dod | 「これが済んだらDone」と言い切れる状態 |
| label | `profile.md` の対応表で決める。1〜2個 |
| priority | `profile.md` の「優先度の既定」で決める |
| due | `profile.md` の「期限の推定」で決める。算出できなければ省略 |

**推測できるものは推測して埋める。** 全部聞き返さない。
`profile.md` が埋まっていれば title / label / priority / due は聞かずに決まるはず。
`summary` と `check` が本当に立たないときだけ質問する。
推測で `due` や `priority` を決めた場合は、報告時に「〜と解釈した」と1行添える。

チェックリストを割るときは「調べる」で止めない。
悪い例: `- [ ] インターンについて調べる`
良い例: `- [ ] 応募したい企業を5社リストアップ` / `- [ ] 各社の締切をカレンダーに入れる` / `- [ ] 応募する3社を決める`

### 2. ラベルを選ぶ

`Study` 学業 / `Career` 就活 / `Work` バイト・インターン / `Circle` サークル /
`Dev` 個人開発・OSS / `Tech` 技術キャッチアップ / `Health` 健康・通院・運動 /
`Life` 生活・手続き / `Money` 学費・奨学金・家計 /
`Idea` ネタ・インプット / `Routine` 定期タスク

判定は `profile.md` の対応表で機械的に行う。この一覧は意味の確認用。

### 3. 起票する

```bash
./scripts/task.sh add \
  --title "サマーインターンのESを提出する" \
  --summary "締切が5/20必着。ガクチカと志望動機の2問。推敲の時間を見て3日前に初稿を上げる。" \
  --label Career --priority P0 --due 2026-05-19 \
  --check "設問と文字数を確認" \
  --check "ガクチカの初稿を書く" \
  --check "志望動機の初稿を書く" \
  --check "先輩かキャリアセンターに見てもらう" \
  --check "推敲してマイページから提出" \
  --dod "マイページで提出完了の表示を確認した"
```

複数タスクをまとめて頼まれたら、1件ずつ `add` を実行する。

### 4. 報告する

作成した Issue 番号・タイトル・ステータス・URL を短くまとめて返す。
複数件なら箇条書き1行ずつ。冗長な確認は不要。

## 注意

- 5分で終わる用事は Issue にしない。その場でやるよう促す。
- 既に似た Issue がないか気になる場合は `./scripts/task.sh list` で確認し、重複していれば
  新規作成せず task-merge スキルの方針に従って既存 Issue にチェック項目を足す。
- 起票直後のステータスは常に `To do`。いきなり `In progress` にはしない。
