# 会社PC用タスクボード（office ブランチ）

会社のタスクと私用のタスクを、**会社PCの1枚のカンバン**で管理するための仕組み。
私用側（[main ブランチ](../../tree/main)）の life ボードと組み合わせて使う。

```
【私用の GitHub】life ボード（スマホ・私用PCから操作）
   │ 変更があるたびに暗号化したコピーを secret gist に書き出す
   ↓
【会社PC】 私用タスク：読むだけ（ログイン不要）
          会社タスク：このPCにだけ保存
          → ブラウザの1枚のボードに並べて表示
```

| | 私用PC・スマホ | 会社PC |
|---|---|---|
| 私用タスク | 編集できる | 見るだけ |
| 会社タスク | 見えない | 編集できる |

- 会社PCには **GitHub のログインもトークンも置かない**。置くのは秘密URLと合言葉だけ
- 会社のタスクは会社PCの `data/tasks.json` にだけ保存され、どこにも送られない
- 通信は「秘密URLのページを読む」だけ。会社PCから外へ送るデータはない

## 必要なもの

macOS に標準で入っているものだけで動く。追加のインストールは不要。

- `git`（初回に「コマンドライン・デベロッパツール」のインストールを求められたら従う）
- `python3`、`openssl`（どちらも macOS 標準）
- Claude Code（話しかけて操作する場合）
- 会社のネットワークから `github.com` / `gist.github.com` に繋がること

## セットアップ（最初の1回だけ）

```bash
git clone -b office https://github.com/Saku052/life-tasks-template.git office-board
cd office-board
./office.py setup
```

`setup` で「秘密URL」と「合言葉」を聞かれるので、私用側で控えておいたものを入れる。
私用タスクが読めたら `設定しました。私用タスク N 件を読み込めました` と出る。

プロフィールも作っておくと、ラベルや優先度の判定が正確になる。

```bash
cp profile.example.md profile.md
```

## 使い方

このフォルダで Claude Code を起動して、話しかけるだけでよい。

```bash
cd office-board && claude
```

```
> ボード開いて
> 金曜までに定例の資料を作らないと
> 今日なにやる
> W3 終わった
```

ボードの画面では、会社のカードをドラッグして列を移動でき、カードを開くとチェックリストを消し込める。
私用のカードは閲覧のみ（🔒）。ボードを開いている間は30秒ごとに自動で最新になる。

直接叩く場合は `./office.py help`。

## 更新

```bash
git pull
./office.py open   # サーバが古ければ自動で起動し直す
```

## 注意

- 会社のタスクはこのPCにしかない。PCを入れ替えるときは `data/tasks.json` を会社が認めている方法で移す
- ボードのサーバは `127.0.0.1` でだけ待ち受ける。止めたいときは `./office.py stop`
- 私用タスクは会社PCの画面に表示される。見られて困る内容は私用側でタイトルをぼかしておく
